# Lotto Number Generator

## Overview

This is a simple web application that generates random lotto numbers.

## Features

*   Generate 6 unique random numbers between 1 and 45.
*   Display the generated numbers to the user.
*   A clean and simple user interface.

## Current Plan

1.  **`index.html`**: Set up the basic HTML structure with a title, a button for generating numbers, and a container to display them.
2.  **`style.css`**: Add styles for a clean and modern look. Center the content, style the button, and create a visually appealing display for the numbers.
3.  **`main.js`**: Implement the JavaScript logic to generate and display the lotto numbers when the button is clicked.
